# Bubble breakup

This repository contains numerical simulations and post-processing tools for the study of **bubble breakup in turbulence**. This is ongoing work.

The repository includes:

- `turbulent_bubble.c`: Basilisk code for the numerical simulations.
- `tracking_script/`: Python tools for post-processing and tracking the dispersed phase.
- `sbatch_files/`: scripts for running simulations on HPC systems.
- `compile.sh`: compilation script.

The post-processing tools are used to analyze the temporal evolution of bubbles and reconstruct their history throughout the simulation.

## Requirements

- Basilisk
- Python 3
